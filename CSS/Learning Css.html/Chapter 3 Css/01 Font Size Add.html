Font Sizing Types

There are many types of font sizing adjustment are there such as:

  • 'em' Tag For Multiply from Parent element by its self
  • 'rem' Tag For Multiply From Html element by its self
  • 'vw'And 'vh' Tag For Giving a Area which are for all devices
  • '%' Tag is used for giving a Area from Parent in Percentage

Property of width and height

  1. min-height: Tag are used to display a unit in limitation by minimum height and from this any type of value which are below that are not be taken as to run.
  2. max-height:Tag are used to display a unit in limitation by maximum height and from this any type of value which are above that are not be taken as to run.
  3. min-width:Tag are used to display a unit in limitation by minimum width and from this any type of value which are below that are not be taken as to run.
  4. max-width:Tag are used to display a unit in limitation by maximum width and from this any type of value which are above that are not be taken as to run.
